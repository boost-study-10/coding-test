### 🧩 풀이 설계 / 막힌 부분
- 처음 접근 아이디어: 배열 앞부분부터 확인하면서 큰수 -> 작은수 있을 때 큰수에서 이익 계산함. 그러나 2 4 9 3 10 같은 경우에선 그럼 9와 10에서 계산하게 되는데, 사실은 10에서 한 번에 계산을 해야 옳은 풀이.
- 막힌 부분 / 해결 방법
2 4 9 3 10  일 경우에는 무조건 마지막날에 파는거 이득
따라서 뒤에서부터 확인할건데 맨 뒤 숫자를 max로 두고
만약 max보다 작은숫자면 이익이 난거니까 answer에다가 추가해주기
만약 max보다 큰 숫자 마주치면 max값 바꿔주기

### 🧠 대략적인 코드 설명
```java
import java.util.Scanner;
import java.io.FileInputStream;

public class Solution {
    public static void main(String[] args) throws Exception {

        Scanner sc = new Scanner(System.in);
		int T;
		T=sc.nextInt();

        for(int test_case = 1; test_case <= T; test_case++) {

            int N = sc.nextInt();
            int[] arr = new int[N];
            for (int i = 0; i < N; i++){
                arr[i] = sc.nextInt();
            }
            
            long answer = 0;
            int max = arr[N-1];
            for (int i = N-2; i >= 0; i--){
                if (arr[i] < max){
                    answer += max - arr[i];
                }

                if (arr[i] > max){
                    max = arr[i];
                }
            }
            
            System.out.println(answer);
        }
    }
}
```
